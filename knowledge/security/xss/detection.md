# XSS 检测与定位

> 覆盖三种类型的检测：存储型、反射型、DOM 型 XSS 的发现方法。
> 检测核心：追踪"输入源 → 输出点"的数据流。

## 漏洞定位的核心思路

检测目标在于发现所有可能导致脚本执行的数据流入点。

## 三种类型的检测方法

三种类型的检测都围绕“输入源 → 输出点”路径进行追踪：

- **存储型检测**：在所有持久化输入点（表单提交、评论、个人资料字段）植入通用测试载荷，访问渲染页面时监控响应内容是否被未编码地嵌入 HTML 结构，或检查浏览器控制台有无脚本执行痕迹。自动化扫描器通过爬取页面并提交带特征的输入，比对前后页面结构变化来识别。
- **反射型检测**：对 URL 参数、POST 参数等即时输入点提交测试载荷，观察响应页面是否原样回显敏感字符（如 `<` `>` `'` `"`）。自动化扫描器通过参数变异和响应分析，结合 HTML 上下文判断是否发生可执行反射。
- **DOM 型检测**：依赖浏览器端分析，通过开发者工具监控 `document.write`、`innerHTML`、`eval` 等危险 API 调用，追踪用户可控数据（如 `location.hash`、`document.referrer`）是否流入这些 API。自动化工具（如 DOM 扫描器）通过注入特定标记并检测 DOM 树中是否出现对应节点来验证。

## 检测覆盖面（金律）

检测需覆盖所有输入源（GET/POST、Cookie、URL 片段、本地存储）及所有输出上下文（HTML 内容、属性、JS 字符串、事件处理器）。建议结合静态代码分析（扫描源码中的危险函数）与动态运行时监控（浏览器的安全审计工具）。
